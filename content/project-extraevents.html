Reactive Music: Extra Events is a fork of CircuitLord's Reactive Music mod, that adds more events, custom event support and compatibility with the popular Prominence™ II: Hasturian Era modpack.

Key Features

Created a modular event registration system that allows custom Validators to be added through a central registry. Each Event is encapsulated in its own Validator class, making the system easy to extend while keeping registration consistent and maintainable.

Integrated my extension framework into the existing codebase while preserving compatibility with legacy songpacks and event syntax. Existing content continued to function unchanged, enabling the project to evolve without disrupting potential users.
