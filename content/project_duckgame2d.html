Duckgame 2D is a small top-down bullet hell. The team consists of 2 programmers (myself included) with both handling all aspects of the game’s systems and features. We occasionally have 2 external artists create art assets as needed.

A key focus of the project has been designing modular, reusable systems that can be leveraged in larger or alternative Unity projects.

Key Contributions

To manage core systems like audio, object pooling, and player input, I built a central Service Locator. Each system was implemented as a self-contained service, easily accessible from anywhere in the game without needing manual setup or scene references. These services are created only when first used, keeping things lightweight and efficient. Once initialised, they persist across scenes, ensuring they're accessibe throughout the game. This approach allowed us to keep our core systems modular.
