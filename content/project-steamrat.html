This project is focused on developing an end-to-end data analytics tool for Steam user reviews. The tool currently has systems for data collection, local database storage, review processing and analytical workflows to help gain insights from player feedback.

Key Releases

The first "complete" version of SteamRAT. This release adds the core dashboard experience, including overall review statistics, language breakdowns, review history, review inspection and N-Gram visualisation.

Since the prototype, the analysis pipeline has been significantly improved by integrating spaCy for more accurate text processing, review simplification and N-Gram generation quality.

The first version of SteamRAT. This release features a .NET 10 Command-Line Tool, that transforms the JSON API responses from the Steam Web API into structured CSV datasets for futher analysis.

One of these datasets included an N-Gram CSV generated from text that I preprocessed with my own algorithm written in C#.
