KACHI MP3 BALANCER

A Lossless MP3 Volume Normaliser Command-Line Tool.

C#
.NET 10
Tools Development
On Going

This project is focused on developing a command-line tool that will scan directories for MP3 files, measure their loudness in decibels, and adjust their volume to a target level without re-encoding, preserving audio quality. It will include an interactive terminal interface for batch or individual file processing, enabling users to preview current volume levels and apply adjustments.
